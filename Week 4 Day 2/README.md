# BSCS — Bhatbhateni Sales Cleaning & Solutions
## Project by Rahul Rimal

This repository contains the PRG 200 sales data cleaning, analysis, visualization, and optional predictive modeling project.

### Project Structure

```text
BSCS_Sales_Project/
├── data/
│   └── bhatbhateni_sales.csv
├── notebooks/
│   └── BSCS_Sales_Analysis_Rahul_Rimal.ipynb
├── images/
│   └── README.txt
└── README.md
```

### Notebook Contents

The notebook covers:
- Library loading
- Dataset loading and inspection
- Data types and summary statistics
- Missing-value detection and cleaning
- Exact duplicate detection and removal
- Transaction ID and line-item validation
- Total amount validation
- Date and city feature engineering
- Univariate analysis
- Sales trends
- Branch and city performance
- Product and category analysis
- Customer analysis
- Payment method analysis
- Correlation and outlier detection
- Optional Random Forest predictive modeling
- Business insights and recommendations

### Data Quality

The raw dataset contains injected null values and duplicate rows. The notebook documents the cleaning decisions and separates the cleaning process from the analysis section.
